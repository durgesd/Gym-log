# 🏋️ GymLog Pro

A professional, offline-first workout tracker that runs as an installable PWA.

## ✨ Features

- 🏋️ **130+ built-in exercises** across all muscle groups
- ✏️ **Create custom exercises** with your own name, muscle group & equipment
- 📝 **Set-by-set logging** with weight, reps, optional RPE and warm-up tagging
- ⏱️ **Rest timer** with sound, vibration and ±15s controls
- 📊 **Progress analytics** — volume trends, muscle distribution, estimated 1RM, PRs, streak
- 📋 **Templates** — save routines and start workouts instantly
- ⚖️ **Body weight tracking** with sparkline chart
- 📤 **Backup & restore** as JSON
- 🌗 **Dark & light themes**
- 💾 **100% offline** — all data stays in your browser's localStorage
- 📲 **Installable** — add to home screen on Android, iOS and desktop
